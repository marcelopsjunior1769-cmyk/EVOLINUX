## Evidência do equipamento que permanece na conversa

As informações a seguir foram fornecidas pelo usuário; não foram obtidas por
esta execução na nuvem:

- Ubuntu 24.04.4 e kernel `7.0.0-38-generic`.
- EVO 16 identificada como `card1`, ID ALSA `EVO16`, USB `2708:000a`.
- Resumo de 54 controles ALSA, incluindo 48 `Analogue 5 Volume`.
- `amixer -c EVO16 cget numid=3`: `Analogue 5 Volume`, índice padrão 0,
  INTEGER, acesso `rw------`, seis posições, mínimo 0, máximo 127, passo 0,
  valores `[0, 0, 0, 0, 0, 0]`.
- Configuração informada: `# CONFIG_SND_DEBUG is not set`, sem linha para
  `CONFIG_SND_CTL_DEBUG`. A verificação por dependência descrita para a 0.5.1
  precisa ser recuperada ou reimplementada; não existe neste runtime 0.3.1.

Esses seis inteiros são a representação exposta pelo ALSA. Não identificam
seis saídas físicas ou fones, e zero não comprova silêncio. O vínculo anterior
MU60/seletor 1/índice 0 precisa ser conferido novamente antes de qualquer
consulta nativa. O numid 3 não é uma identidade universal.

O relato anterior de áudio sem cortes refere-se à leitura de ganho pelo
`amixer`. Não comprova continuidade na matriz, execução nativa ou funcionamento
da GUI. A consulta `amixer` da matriz e os testes simulados são evidências
distintas.

## Verificação desta recuperação

Na raiz dos fontes restaurados:

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
PYTHONPATH=src python3 -m evolinux --version
PYTHONPATH=src python3 -m evolinux --help
```

Os **198 testes passaram** na nuvem em 25/10/2026, com transportes simulados.
Esse resultado não é o conjunto de 447 testes relatado anteriormente para a
0.5.1 e não comprova funcionamento no equipamento. `--version` deve informar
`EVOLINUX 0.3.1`. Esta cópia ainda não oferece o comando `gui`.

Não foram executados comandos ALSA/USB no equipamento, alterações de áudio,
módulos experimentais ou firmware. Os comandos históricos `status`,
`doctor --controls` e `plan-set` usam o backend anterior, que consulta INFO.
Como o driver pode realizar SET_CUR interno durante inicialização de faixas,
não fazem parte da validação física somente leitura pretendida para a GUI.
Não se deve usar a sequência antiga como substituta do backend sem INFO.
